- [[Solvência Geral (Margem de Garantia)]]
- [[Capital Circulante Líquido (CCL)]]

|                                       | **ÍNDICES DE LIQUIDEZ**                                                          |
| ------------------------------------- | -------------------------------------------------------------------------------- |
| **IMEDIATA**<br>(Instantânea)         | $$ \frac{Disponivel}{PC} $$                                                      |
| **CORRENTE**<br>(Comum)               | $$ \frac{AC}{PC} $$​                                                             |
| **SECA**<br>(Teste Ácido)             | ​$$ \frac{AC - Estoques}{PC} = \frac{AC - Estoques - DespesasAntecipadas}{PC} $$ |
| **GERAL**<br>(Total)                  | $$ \frac{AC + ARLP}{PC + PNC} $$                                                 |
| **SOLVÊNCIA**<br>(Margem de Garantia) | $$ \frac{AC + ANC}{PC + PNC} = \frac{AtivoTotal}{PassivoExigivel} $$​            |
| **CAPITAL CIRCULANTE LÍQUIDO**        | $$ CLL = AC - PC $$                                                              |
