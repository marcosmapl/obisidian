

## Encontros Consonantais Perfeitos (ou Inseparáveis)

> [!note] Ocorrem quando as consoantes **permanecem na mesma sílaba.**

| Encontro | Exemplo     |
| -------- | ----------- |
| **bl**   | blo-co      |
| **br**   | bra-vo      |
| **cl**   | clo-ro      |
| **cr**   | cromo       |
| **dr**   | dra-gão     |
| **fl**   | flo-ra      |
| **fr**   | fran-cês    |
| **gl**   | glo-ri-o-so |
| **gr**   | gran-de     |
| **pl**   | pla-no      |
| **pr**   | pra-to      |
| **tr**   | tri-bo      |

---
## Encontros Consonantais Imperfeitos (ou Separavéis)

> [!note] Acontecem quando as consoantes **pertencem a sílabas diferentes e consecutivas**

| Encontro Consonantal | Exemplo      |
| -------------------- | ------------ |
| **dv**               | ad-ven-to    |
| **bt**               | ob-tu-so     |
| **pt**               | ap-to        |
| **cs**               | fúc-sia      |
| **ct**               | pac-to       |
| **cç**               | suc-ção      |
| **ft**               | naf-ta       |
| **bl**               | sub-lo-car   |
| **gn**               | in-cóg-ni-ta |
| **tn**               | ét-ni-co     |
| **st**               | cons-tar     |
