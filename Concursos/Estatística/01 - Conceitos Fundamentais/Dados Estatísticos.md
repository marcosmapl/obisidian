## Conceito

> [!note] Dados Estatísticos
> Os dados estatísticos constituem os valores resultantes da etapa de coleta de informações dentro de uma pesquisa. Eles referem-se a um conjunto de valores organizados por meio de variáveis (a característica que está sendo medida) e observações (os elementos da amostra ou população, como peso, altura ou idade.

---
## Classificação

Com relação à quantidade de observações registradas para cada indivíduo, os dados podem ser classificados em:

- **Dados Univariados:** Quando uma única observação de cada indivíduo é registrada. Exemplo: peso.
- **Dados Bivariados:** Quando duas observações de cada indivíduo são registradas. Exemplo: peso, altura.
- **Dados Multivariados:** Quando mais de duas observações acerca de cada indivíduo são registradas. Exemplo: peso, altura, sexo e idade.

---
## Formas de Apresentação dos Dados

Quanto à organização e forma de apresentação, o material distingue dois estados fundamentais:

### Dados Brutos

São os valores na forma como foram coletados, sem qualquer organização numérica de ordem crescente ou decrescente. Frequentemente são apresentados em uma **tabela primitiva**, que oferece pouca informação útil ao leitor e exige organização posterior para tornar os dados expressivos.

### Rol

O **rol** é a organização dos dados brutos em uma ordem de grandeza, que pode ser **crescente ou decrescente**. A principal vantagem do rol é permitir a identificação imediata do **menor** e do **maior** elemento do conjunto.

- **Amplitude Total (AT):** É a diferença entre o maior e o menor valor observados no rol (AT=Xmax​−Xmin​).
