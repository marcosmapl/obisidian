

O **Montante Simples cresce linearmente** enquanto o **Montante Composto cresce exponencialmente**.

![[Pasted image 20260811211150.png]]

Observe que os gráficos se cruzam. Neste ponto, o **tempo de aplicação é igual a 1 unidade de tempo**.

Quando a ==unidade de tempo é menor que 1==, o **Montante Simples é MAIOR que o Montante Composto** e, consequentemente, o Juro Simples é MAIOR que o Juro Composto.

Quando a **unidade de tempo é maior que 1**, o **Montante Composto é MAIOR que o Montante Simples** e, consequentemente, o Juro Composto é MAIOR que o Juro Simples.
